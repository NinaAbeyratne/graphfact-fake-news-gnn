# GraphFact: Fake News Detection using NLP and Graph Neural Networks

This project detects fake news using transformer-based NLP embeddings and Graph Neural Networks.

## Main Components

- Text preprocessing
- Transformer embeddings
- Article similarity graph construction
- GNN-based fake news classification
- REST API
- Lightweight frontend demo

## Tech Stack

- Python
- Google Colab
- Sentence Transformers
- PyTorch Geometric
- FastAPI
- Streamlit
